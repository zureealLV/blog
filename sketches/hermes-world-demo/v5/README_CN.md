# V5 本地 Demo

入口：<http://127.0.0.1:8767/v5/>。只绑定 `127.0.0.1`，不是公网地址。

```powershell
Set-Location 'D:/blog/Firefly_zureeallv/sketches/hermes-world-demo/v5'
corepack pnpm install --ignore-workspace --frozen-lockfile
./Start-Demo.ps1
```

启动脚本发现 V5 服务已在运行时直接显示入口，不重复启动；其他服务占用端口时不结束对方进程。可用 `./Start-Demo.ps1 -Port 8768` 换端口。

## 已实现

1. **全量文章**：当前 194 篇，Hermes 150 / 随笔 36 / 技术 8。正式目录只读；草稿、加密文章整体排除，不读 staging。服务检查新增、修改、删除，页面自动同步；全文按需请求。
2. **全画幅房间**：背景 `cover` 保持比例，不拉伸人物。雨窗远景、中央记忆场、右侧竖屏和前景结构分层；手机改成上部人物、下部星域，不缩放整张桌面。
3. **克制的科技感**：石墨与蓝绿、局部暖光、玻璃反射和扫描纹理。星图默认静止，动效服务镜头；不做满屏装饰粒子和假日志。
4. **不是电脑桌**：没有实体显示器底座和键盘。人物固定使用用户认可的 V4 四帧图集，放进独立竖屏，正常比例。
5. **真实 3D**：Three.js 0.180.0，XYZ 节点、PerspectiveCamera、旋转视角与深度缩放。点击星区→节点→简介→阅读全文→原位返回。单个可替换镜头动画，无排队；仅选中文章的最多 3 条关键词关联线。
6. **去装饰文字**：默认没有标题栏、编号、口号、署名或假状态。只有工具图标，主题名在靠近/悬停/键盘聚焦时出现；文章标题与简介在选择后出现；角色对白需主动交互。

## 操作

- 点击星群进入主题，点击星点查看简介；拖动旋转，滚轮缩放。
- 左下四个入口：返回、搜索筛选、主题选择、设置。
- `/` 搜索；Esc 返回或关闭当前弹窗；Tab/Enter 操作控件。
- 星图画布可键盘聚焦，方向键旋转，+ / − 缩放，Enter 进入最近可见对象。
- 设置中切换静态、低性能列表、暖光；系统减少动态设置自动生效。
- 相机历史、选择、筛选保存在当前浏览器标签页的 sessionStorage；不保存正文。

## 明确限制

- 房间是 GPT 生成的二维建筑背景；**星图是实时 WebGL 3D**，不是整间房间都可自由行走的 3D 游戏。
- 主题/关联是关键词规则，不是语义向量模型；有低置信度与未归类兜底，支持少量人工纠正。当前主题大小不刻意均分，分类仍可能不准确。
- 阅读器支持经过清理的基础 Markdown 正文；不执行 MDX，不完整复刻 Astro 插件、图片、数学和 Mermaid。要看完整图文版请点“打开博客原文”。
- 192 篇简介在 60–100 字范围；两篇正文仅有极短文本/媒体内容，保留原有短文本，不编造内容凑字数。
- 人物为四帧表情切换，不是 Live2D。素材/字体授权需要未来发布前单独审查。
- 浏览器验收是本机 Edge/Chromium 与移动视口模拟，不等于真机 Safari 或所有低端 GPU 验收。未做生产 Astro/Swup 集成，未修改生产目录。

源码、启动、测试、素材记录都在本目录。英文总览见 `README.md`；索引细节见 `INDEX.md`；真实截图与测试说明见 `TESTING.md`。

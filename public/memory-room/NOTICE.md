# Memory Room — sources and scope

- Room background: generated with the built-in GPT image tool for this project; the first image's fixed display niche was removed in a second GPT edit, so the actual portrait display can adapt to viewport size. Exact prompts are recorded in `sketches/hermes-world-demo/v5/PROMPTS.md` in the source repository.
- Character: the approved reference-guided V4 expression atlas, reused unchanged. Four expression frames, not Live2D or a live model connection. This notice does not claim ownership of the reference character or grant third-party character rights.
- Three.js: vendored official minified ES modules, version **0.180.0**. Copyright and MIT license: `vendor/LICENSE.three.txt`. These are required runtime assets, not the site's generated build output.
- Production typography uses system fonts. The prototype's Zpix font is not redistributed by this page.
- The background is a 2D illustration; the article field uses XYZ geometry and a real perspective camera. Themes and links are keyword rules, not semantic embeddings.
- Article metadata and sanitized basic Markdown reader payloads are generated by Astro from public content during each build. Draft and password-protected entries are excluded. The reader omits images and complex MDX/diagram rendering; the original article link provides the full page.
- No live local server, cloud model, account, telemetry or remote asset CDN is required by the room.

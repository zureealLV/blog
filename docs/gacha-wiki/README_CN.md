# osu! gacha 中文战术图鉴

正式入口：<https://zureeallv.com/gacha-wiki/>。博客「我的 → Gacha Wiki」也可进入。

## 可以做什么

- 中英文名称、效果、MOD 缩写搜索；支持多个关键词同时匹配。
- 分类查看职业、战技、被动、专属联动、MOD、组合、签名技能、阵容羁绊、楼层、Boss、状态和养成机制。
- 查看完整数值、英文原文、关联条目、逐星 MOD 固有效果和主词条生成方向。
- 搭配实验台选择普通或签名技能，以及最多三种 MOD；检查专属联动、三件组合覆盖两件组合、无攻击签名和转盾上限注意事项。
- 12 套基于规则的手册，包含词条方向、行动思路、队友方向及使用限制，并可一键带入实验台。
- 收藏条目、复制条目或搭配链接、下载规则和手册 JSON。

## 使用边界

没有登录或读取用户账号。收藏只存当前浏览器，不同步设备。
实验台不是伤害/胜率模拟器；它不会猜测角色等级、星魂、MOD 词条或敌人状态。
签名技能是公开前端的技能原型，不是当期卡池或全部角色卡清单。
攻略明确为规则推导，不是官方最优配置。

原站更新后不会自动同步。当前抓取日期、源文件名、SHA-256 和英文原文都可在 Wiki 内核对。
刷新与测试流程见 [README](README.md)。未知来源 hash 必须人工审核后才能更新，不能静默用旧提取映射套新规则。
